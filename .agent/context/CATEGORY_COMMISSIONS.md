## РАСЧЕТ РЕАЛЬНОЙ КОМИССИИ

### Формула для Ozon:

```
Комиссия = Базовая ставка категории × Цена (с учетом скидок)
```

### Формула для Wildberries:

```
Комиссия = (КВВ + Тарифная опция - СПП + кМ) × Цена
```

**Где:**

- **КВВ** — базовая ставка категории
- **Тарифная опция** — Базовый (+2.5-3.2%) или Премиум (+4.5%)
- **СПП** — скидка постоянного покупателя (вычитается из комиссии WB)
- **кМ** — коэффициент для товаров в акциях

## ПРИМЕРЫ РАСЧЕТОВ

### Пример 1: Футболка на Ozon

**Данные:**

- Категория: Одежда
- Цена: 800₽
- Схема: FBO

**Расчет:**

- Базовая комиссия: 24%
- НО! Если цена 301-500₽ → 14%
- Для 800₽ → 24%
- Комиссия = 800 × 0.24 = **192₽**

### Пример 2: Футболка на Wildberries

**Данные:**

- Категория: Одежда
- Цена: 800₽
- КВВ: 25% (после повышения июня 2025)
- Тариф: Базовый (+3%)
- СПП: 5%
- Акция: нет

**Расчет:**

- Комиссия = (25% + 3% - 5%) × 800
- Комиссия = 23% × 800 = **184₽**

### Пример 3: Электроника на Ozon

**Данные:**

- Категория: Электроника
- Цена: 5000₽
- Схема: FBS

**Расчет:**

- Базовая комиссия: 12%
- Комиссия = 5000 × 0.12 = **600₽**

## СТРАТЕГИИ ОПТИМИЗАЦИИ

### 1. Используйте льготные ставки Ozon

- Товары до 300₽: фиксированные 14-20%
- Fashion 301-500₽: 14% вместо 24%

### 2. Учитывайте СПП на Wildberries

- Скидка постоянного покупателя вычитается из комиссии WB
- Не влияет на ваш доход напрямую

### 3. Избегайте высококомиссионных категорий

- Если маржа <30%, одежда/обувь = риск убытков
- Лучше электроника или книги

### 4. Мониторьте изменения

- Комиссии меняются 2-3 раза в год
- Подписывайтесь на новости МП
