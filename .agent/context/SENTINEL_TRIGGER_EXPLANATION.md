## 💡 РЕКОМЕНДАЦИИ

### 1. Увеличьте буфер для Ozon

**Текущий:** 5% (default)  
**Рекомендуемый:** 10-15% для Ozon

**Почему:**

- Ozon Card дает до 30% скидки
- Буфер 5% не покрывает эту скидку
- Рекомендуется 10-15% для безопасности

**Как настроить:**

```sql
UPDATE users SET price_buffer_percent = 15 WHERE id = YOUR_ID;
```

### 2. Настройте буфер для конкретного товара

Если товар участвует в акциях:

```sql
UPDATE products
SET card_discount_buffer = 20
WHERE id = PRODUCT_ID;
```

### 3. Проверьте реальную цену на Ozon

Зайдите на страницу товара и проверьте:

- Базовую цену
- Цену с Ozon Card
- Участие в акциях
