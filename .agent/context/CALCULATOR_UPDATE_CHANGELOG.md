### 2. ВОЗВРАТЫ

```typescript
// Логистика туда-обратно
const returnCosts = Math.round(logistics * 2 * returnRate);
```

## 🔧 ИСПРАВЛЕННЫЕ БАГИ

### 1. Неверный расчет хранения WB

**Было:**

```typescript
const otherCosts = COMMISSIONS.WB.storage * 5; // 2.5₽ * 5 = 12.5₽ за 5 дней
```

**Стало:**

```typescript
const otherCosts = Math.round(COMMISSIONS.WB.storage * 30); // 0.08₽ * 30 = 2.4₽ за месяц
```

**Исправление:** Завышение в **5 раз** устранено!

### 2. Отсутствие эквайринга Ozon

**Было:**

```typescript
const otherCosts = COMMISSIONS.Ozon.processing; // 30₽
```

**Стало:**

```typescript
const otherCosts = COMMISSIONS.Ozon.processing + Math.round(price * COMMISSIONS.Ozon.acquiring);
// 30₽ + 1.5% от цены
```
