### ⚠️ ПОТЕНЦИАЛЬНЫЕ УЛУЧШЕНИЯ

#### 1. **Расчет "сэкономленной суммы" может быть неточным**

**Проблема:**

```typescript
// sentinel.ts, строка 396
const savedAmount = minPrice - currentPrice;
```

**Пример:**

- `minPrice` = 1000₽
- `currentPrice` = 800₽ (обнаружено)
- `savedAmount` = 1000 - 800 = **200₽**

**НО!** Если Sentinel установил цену в `minPrice` (1000₽), то реально сэкономлено:

- Разница между тем, что могло быть продано по 800₽ и тем, что будет продано по 1000₽
- Это **не 200₽ экономии**, а **200₽ разницы в цене**

**Правильнее:**

```typescript
// Если защита сработала — мы ПРЕДОТВРАТИЛИ продажу по низкой цене
// "Сэкономлено" = разница между минимумом и обнаруженной ценой
const savedAmount = minPrice - currentPrice; // ✅ Это корректно для "предотвращенного убытка"
```

**Вывод:** Логика **верная**, но название может вводить в заблуждение. Лучше назвать `preventedLoss` (предотвращенный убыток).

---

#### 2. **Нет учета комиссий маркетплейса при расчете убытка**

**Проблема:**
Sentinel считает "сэкономленную сумму" как разницу цен, но не учитывает, что:

- При цене 800₽ комиссия WB 20% = 160₽
- При цене 1000₽ комиссия WB 20% = 200₽
- Реальная экономия = (1000 - 200) - (800 - 160) = **800 - 640 = 160₽**, а не 200₽

**Рекомендация:**
Добавить расчет с учетом комиссий:

```typescript
const commissionRate = 0.2; // Зависит от категории
const netLowPrice = currentPrice * (1 - commissionRate);
const netMinPrice = minPrice * (1 - commissionRate);
const realSavedAmount = netMinPrice - netLowPrice;
```

---

#### 3. **Нет проверки на минимальную цену маркетплейса**

**Проблема:**
Если `minPrice` < минимальной цены маркетплейса, API вернет ошибку.

**Пример:**

- Ozon: минимальная цена 1₽
- WB: минимальная цена зависит от категории

**Рекомендация:**
Добавить валидацию перед вызовом API:

```typescript
const MIN_MARKETPLACE_PRICE = 1;
if (minPrice < MIN_MARKETPLACE_PRICE) {
  console.error(`❌ Min price ${minPrice} is below marketplace minimum ${MIN_MARKETPLACE_PRICE}`);
  return;
}
```
