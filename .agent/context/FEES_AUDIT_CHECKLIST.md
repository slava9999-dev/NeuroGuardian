## ✅ ПРОВЕРКА ФОРМУЛ

### Минимальная цена для безубыточности:

```
Мин. цена = Себестоимость / (1 - Все комиссии%)
```

**Пример:** Себестоимость 400₽, комиссии 40%

- Расчет: 400 / (1 - 0.4) = 400 / 0.6 = 666.67₽ ✅
- Округлено: 667₽ ✅

### Чистая прибыль:

```
Прибыль = Цена - Комиссия - Логистика - Хранение - Эквайринг - Возвраты - Невыкупы - Себестоимость
```
