## 💰 ФОРМУЛА РЕАЛЬНОЙ ПРИБЫЛИ

```
Чистая прибыль = Цена товара
  - Комиссия маркетплейса (%)
  - Логистика туда
  - Логистика обратно (возвраты %)
  - Хранение (дни x тариф)
  - Эквайринг (%)
  - Невыкупы (% x логистика)
  - Себестоимость
```

**Минимальная цена для безубыточности:**

```
Мин. цена = Себестоимость / (1 - Все комиссии%)
```

**Пример:** Себестоимость 400₽, комиссии 40% → Мин. цена = 400 / 0.6 = **667₽**

## 🛡️ БЫСТРЫЕ РЕКОМЕНДАЦИИ

### Перед добавлением товара:

1. Рассчитайте юнит-экономику с учетом **ВСЕХ** комиссий
2. Заложите 10-15% на возвраты
3. Учтите хранение (оборачиваемость)
4. Проверьте категорию (разные комиссии)

### FBO vs FBS:

- **FBO:** Если оборачиваемость <160 дней, объем >100 заказов/мес
- **FBS:** Если сезонный товар, есть свой склад, КГТ

### Участие в акциях:

- **Обязательно рассчитайте** рентабельность со скидкой
- **Минимум 10% маржи** после всех расходов
- **WB:** Участие критично для видимости
- **Ozon:** Могут добавить автоматически

### Защита от возвратов:

- Качественные фото (5+ ракурсов)
- Точные размеры и описания
- Видеообзоры
- Ответы на вопросы
