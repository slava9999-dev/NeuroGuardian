## ❌ ПРОБЛЕМЫ

### 1. "Спасено: 0₽" — Вводит в заблуждение

**Проблема:** Когда `currentPrice` = `minPrice`, показывается "Спасено: 0₽"  
**Почему:** Цена уже была на минимуме, но Sentinel сработал превентивно  
**Впечатление:** "Зачем тогда сработал?"

### 2. Длинное название товара

**Проблема:** Название обрезается в уведомлении  
**Пример:** "Держатель для полотенец настенный 1000 мм - черный, дизайнерская вешалка..."  
**Впечатление:** Неудобно читать

### 3. Неясный статус

**Проблема:** "АТАКА ОБНАРУЖЕНА!" звучит одинаково для всех случаев  
**Реальность:** Могут быть разные сценарии:

- Цена упала ниже минимума (реальная атака)
- Цена на минимуме (превентивная защита)
- Цена приближается к минимуму (предупреждение)
