## 1. МОДУЛЬ ЦИФРОВОГО ЗРЕНИЯ (VisionCore)
**Цель:** Автоматический контроль качества и анализ контента перед публикацией.

* **Technology:** Google Gemini 2.0 Pro Vision (Multimodal).
* **Pipeline анализа:**
    1.  Принимаем RAW-фото от мастера.
    2.  **Visual QA Check:** Агент должен вернуть JSON с оценкой:
        - `lighting_score`: (0-10)
        - `blur_detected`: boolean
        - `material_detected`: "oak" | "ash" | "resin" | "unknown"

## 2. КОНВЕЙЕР ГЕНЕРАЦИИ (RenderFactory)
**Цель:** Превращение фото "из цеха" в продающую карточку (Rich Content).

* **Интеграция:** Подключи API для генерации (рекомендую Replicate с Flux.1 или Google Vertex Imagen).
* **Сценарии (Workflows):**
    * **Workflow A (Main Card):** Remove Background -> Place on Pure White (#FFFFFF) -> Add Soft Shadow -> Upscale.
    * **Workflow B (Lifestyle):** Remove Background -> Generate Prompt ("Luxury loft interior, concrete walls, warm lighting") -> Composite Product -> Harmonize Lighting.
* **Требование:** Сохранение геометрии товара. Дерево нельзя искажать. Использовать ControlNet или аналогичные техники фиксации контуров.

## 3. АСИНХРОННАЯ АРХИТЕКТУРА (Industrial Reliability)
Обработка фото занимает время (10-40 сек). Синхронный запрос "убьет" сервер.

* **Queue System:** Внедрить `Upstash QStash` или `BullMQ` (Redis).
* **Flow:**
    1.  User Upload -> API (200 OK, Job ID).
    2.  Worker Process -> Vision Check -> Generation -> Upload to Cloud Storage.

## 1. МОДУЛЬ "CTR PREDICTOR" (NEURO-VISION)
**Задача:** Мы не публикуем фото, пока не будем уверены, что на него кликнут.
**Логика:**
1.  Агент берет сгенерированное фото (из RenderFactory).
2.  Сравнивает его с ТОП-10 конкурентов по запросу "журнальный столик".
3.  Использует Gemini Vision Pro для анализа:
    * **Contrast Score:** Выделяется ли наш товар на фоне выдачи?
    * **Focus Map:** Куда падает взгляд? (Должен на текстуру дерева, а не в угол).
4.  **Output:** Если оценка ниже 8/10 -> Автоматический перерендеринг с другим светом/ракурсом.

## 2. МОДУЛЬ "SEMANTIC MINER" (SEO-AGRESSOR)
**Задача:** Забрать 100% поискового трафика, включая низкочастотные запросы.
[cite_start]**Интеграция:** Расширяем `ProductsSpecialist`[cite: 61].
**Алгоритм:**
1.  **Competitor Review Parsing:** Скачать последние 1000 отзывов конкурентов.
2.  **Pain Point Extraction:** Найти, на что жалуются люди (пример: "шатается", "дешевый лак", "сложная сборка").
3.  **Weaponized Description:**
    * Если у конкурентов "шатается" -> Наш Агент пишет в H1/Description: "Монолитная устойчивость", "Стальной каркас", "Никакого люфта".
    * Внедрение LSI-ключей (синонимов), которые конкуренты упускают (например, не просто "стол", а "кофейная станция", "подставка под ноутбук").
4.  [cite_start]**Auto-Update:** Если появляется новый трендовый ключ в Analytics API[cite: 52], агент сам добавляет его в скрытые поля карточки.
