## 🎯 ЦЕЛЬ ПРОЕКТА

NeuroGUARDIAN — Telegram WebApp для автоматической защиты маржи продавцов на маркетплейсах (WB, Ozon) от принудительных акций.

**Функционал:**

- Мониторинг цен товаров каждые 60 секунд (клиентский polling)
- Stop-Loss защита: если цена упала ниже min_price → автоматическое действие
- Два режима: Zero Stock (обнуление остатков) или Price Correction (восстановление цены)
- Telegram уведомления при срабатывании защиты
- Звуковые алерты в приложении

## ⚠️ ИЗВЕСТНЫЕ ПРОБЛЕМЫ

### 1. Ozon API Key деактивация

**Проблема:** Ozon автоматически деактивирует ключи попавшие в открытый доступ
**Решение:** Пользователь должен создать новый ключ и ввести его в приложение

### 2. Cron Jobs лимит

**Проблема:** Vercel Hobby план — максимум 2 cron jobs на аккаунт
**Решение:** Убрали cron из vercel.json, используем клиентский polling

## 📝 ФОРМАТ ВВОДА OZON API

В приложении есть 2 поля:

- **Client ID:** числовой ID (например `2820442`)
- **API Key:** UUID формат (например `7bc0e79f-dc16-471e-a2eb-0b14c4dbd1dd`)

Система автоматически комбинирует их в формат `clientId:apiKey` для сохранения.
