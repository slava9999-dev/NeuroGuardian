## ⚠️ Известные ограничения

### 1. initData в Telegram WebApp

**Проблема:** У некоторых пользователей initData приходит пустым при открытии через Telegram.

**Причина:** Неправильная настройка Menu Button в BotFather или кеш Telegram.

**Решение:**

1. В @BotFather → `/mybots` → Bot Settings → Menu Button
2. Указать чистый URL: `https://neuro-guardian.vercel.app`
3. Полностью перезапустить Telegram

**Workaround:** Admin API для управления товарами через консоль.

### 2. Wildberries API

**Статус:** Структура готова, требует тестирования с реальными ключами.

## 🔧 Admin API Endpoints

```
GET /api?action=admin-check-user&userId=XXX
GET /api?action=admin-list-users
GET /api?action=admin-list-products&userId=XXX
GET /api?action=admin-reset-statuses&userId=XXX
GET /api?action=admin-test-telegram&userId=XXX
GET /api?action=admin-activate-trial&userId=XXX&days=3
POST /api?action=admin-set-protection (userId, enabled)
POST /api?action=admin-set-defense-mode (userId, mode)
```

Все защищены заголовком: `X-Admin-Key: [ADMIN_API_KEY]`

## 📊 База данных (Postgres)

### Таблицы:

- `users` — пользователи, подписки, API ключи
- `products` — товары с ценами и статусами
- `transactions` — история платежей

### Ключевые поля products:

- `product_id` — формат `ozon-{id}` или `wb-{nmId}`
- `min_price` — Stop-Loss уровень
- `current_price` — актуальная цена с маркетплейса
- `status` — active/protected/triggered

## 🧪 Тестирование Sentinel (консоль)

```powershell
# 1. Сброс статусов
Invoke-RestMethod -Uri "https://neuro-guardian.vercel.app/api?action=admin-reset-statuses&userId=USER_ID" -Headers @{"X-Admin-Key"="KEY"}

# 2. Установка Stop-Loss
$body = @{action="products"; productId="ozon-XXX"; minPrice=5000; userId=USER_ID} | ConvertTo-Json
Invoke-RestMethod -Uri "https://neuro-guardian.vercel.app/api" -Method POST -Body $body -ContentType "application/json" -Headers @{"X-Admin-Key"="KEY"}

# 3. Запуск Sentinel
Invoke-RestMethod -Uri "https://neuro-guardian.vercel.app/api?action=check-prices&debug=true" -Headers @{"X-Admin-Key"="KEY"}
```
