## 🎯 Что это такое?

**NeuroGUARDIAN** — это интеллектуальная SaaS-платформа для продавцов на маркетплейсах Wildberries и Ozon. Система автоматически защищает вашу прибыль, отслеживает конкурентов и помогает принимать правильные решения по ценообразованию.

### Для кого?

- 🏪 **Продавцы на WB/Ozon** с каталогом от 10 до 10,000+ товаров
- 📊 **Менеджеры маркетплейсов**, которым нужна аналитика в реальном времени
- 🤖 **Бизнесы**, желающие автоматизировать рутинные операции

### Главная проблема, которую решаем:

**Маркетплейсы могут снижать цену вашего товара без вашего ведома** (промо-акции, WB Wallet, Ozon Card), что приводит к продажам в убыток. NeuroGUARDIAN отслеживает **реальную цену покупателя** и мгновенно уведомляет вас через Telegram.

## ✨ Основные возможности

### 🛡️ Sentinel (Страж цен)

- **Автоматический мониторинг** цен каждые 30 минут (настраиваемый Cron).
- **Детекция скрытых скидок**: Учитывает WB Wallet, Ozon Card и акции, которые не видны в API продавца.
- **Stop-Loss защита**: Система блокирует снижение цены, если она падает ниже маржинального минимума.
- **Telegram-алерты**: Уведомления с кнопками действий: "🔍 Проверить", "🛑 Остановить продажи", "✅ Подтвердить защиту".
- **BrowserEyes технология**: Использование реального headless-браузера для проверки цен "глазами покупателя".

### 🤖 Viktor AI (Умный помощник)

- **Мультиагентная архитектура**: 6 специализированных агентов:
  - `ChatSpecialist` — маршрутизация и общие вопросы.
  - `ProductsSpecialist` — работа с каталогом и ценами.
  - `PricingSpecialist` — расчет юнит-экономики и установка Stop-Loss.
  - `SentinelSpecialist` — управление защитой и логами угроз.
  - `AnalyticsSpecialist` — анализ продаж и остатков.
  - `SupportSpecialist` — база знаний по правилам маркетплейсов.
- **RAG (Retrieval-Augmented Generation)**: Контекстный поиск по базе знаний (лимиты, штрафы, стратегии 2025).
- **Голосовое управление**: Поддержка Web Speech API и ElevenLabs для голосовых ответов.

### 📊 Аналитика и Юнит-экономика

- **Калькулятор чистой прибыли**: Учитывает комиссию (5-25%), логистику (включая габариты), налоги и маркетинг (DRR).
- **ABC-анализ**: Классификация товаров по доходности.
- **Прогноз стоков**: Расчет дней до Out-of-Stock (OOS).

### 🏹 Hunter Mode (Режим охотника)

- **Мониторинг конкурентов**: Отслеживание цен конкретных SKU конкурентов.
- **Динамический репрайсинг**: Стратегии "Держать ниже на 1%" или "Следовать за рынком".
- **Защита от демпинга**: Умное снижение цены только до уровня Stop-Loss.

## 🔑 Ключевые компоненты

### 1. `SentinelOrchestrator.ts`

Мозг системы защиты.

- Запускает проверки товаров.
- Вызывает `ThreatDetector` для анализа цен.
- Принимает решения о корректировке цен (автоматически или через подтверждение).

### 2. `MultiAgentOrchestrator.ts`

Ядро ИИ-помощника.

- **Intent Classification**: Определяет намерение пользователя (Чат, Цены, Аналитика).
- **Routing**: Передает задачу нужному специалисту (`Specialist`).
- **Tool Execution**: Безопасное выполнение инструментов с валидацией аргументов.

### 3. `BrowserEyes.ts`

Модуль "Зрения".

- Запускает Headless браузер.
- Эмулирует поведение реального пользователя.
- Обходит защиту от ботов (Stealth Mode) для получения цены WB Wallet.

### 4. `VectorStore.ts` (RAG)

Система знаний.

- Хранит эмбеддинги документации.
- Выполняет семантический поиск для ответов на сложные вопросы о правилах площадок.

## ⚙️ Как это работает (Workflow)

### Сценарий: Защита от убытка (Stop-Loss)

1. **Cron-задача** вызывает Sentinel каждые 30 мин.
2. **Сканирование**: Получение текущих цен через API WB/Ozon.
3. **Проверка "Глазами"**: BrowserEyes заходит на страницу товара и берет цену для покупателя.
4. **Анализ угрозы**:
   - Если `Цена покупателя < Stop-Loss`: Создается угроза типа `BUYER_PRICE_BELOW_STOPLOSS`.
   - Если активна промо-акция: `PROMO_PRICE_VIOLATION`.
5. **Реакция**:
   - Бот отправляет алерт в Telegram.
   - Пользователь нажимает "✅ Исправить".
   - Система обновляет цену в API маркетплейса.

### Сценарий: Чат с Виктором

1. Пользователь пишет: "Какая у меня чистая прибыль по артикулу 123?"
2. **Оркестратор** классифицирует интент -> `ANALYTICS`.
3. **AnalyticsSpecialist** получает задачу.
4. Агент вызывает инструмент `calculate_unit_economics`.
5. Результат форматируется в текст и возвращается пользователю.

## 🔒 Безопасность

1. **Шифрование ключей**: API ключи маркетплейсов хранятся в БД в зашифрованном виде (AES-256).
2. **Pseudo-RASP**: Встроенная защита от инъекций (SQLi, XSS) на уровне middlewares.
3. **Billing Guard**: Блокировка API вызовов для неоплаченных аккаунтов.
4. **Безопасные Тулы**: Критические действия (смена цен) требуют подтверждения пользователя (Human-in-the-loop).
