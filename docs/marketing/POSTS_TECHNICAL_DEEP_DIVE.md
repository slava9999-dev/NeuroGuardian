## 🛡️ Пост 1: Безопасность NeuroGUARDIAN

### Версия для VK (длинная)

**Заголовок:** Как мы защищаем ваш бизнес: архитектура безопасности NeuroGUARDIAN

**Текст:**

Когда речь идёт о доступе к вашим API ключам WB и Ozon, безопасность — не опция, а обязательное требование.

Мы прошли полный аудит безопасности по стандарту OWASP Top 10 и готовы рассказать, как именно защищаем ваши данные:

**🔐 Шифрование на уровне базы данных**

Все API ключи шифруются AES-256 перед сохранением. Даже если злоумышленник получит доступ к базе данных — он увидит только зашифрованные строки.

```typescript
const encryptedKey = encrypt(apiKey, process.env.ENCRYPTION_KEY);
// Результат: "U2FsdGVkX1..." вместо "eyJhbGc..."
```

**🚫 Защита от SQL-инъекций**

Все запросы к базе данных параметризованы. Мы не используем конкатенацию строк — только prepared statements.

**✅ Валидация Telegram WebApp**

Каждый запрос от Telegram проверяется криптографической подписью. Подделать запрос невозможно без секретного ключа бота.

**🔒 Rate Limiting**

Максимум 100 запросов в минуту на пользователя. Это защищает от DDoS и скликивания.

**📊 Аудит действий**

Все критические операции (изменение стоп-лосса, обновление цен) логируются с IP-адресом и временем. Вы всегда можете проверить историю.

Виктор — это не просто чат-бот. Это полноценный AI-агент с памятью, инструментами и способностью учиться на ошибках.

**🧠 Архитектура агента**

```
Запрос пользователя
    ↓
┌─────────────────────────────────────┐
│ 1. PLANNER (Планировщик)            │

    ↓

└─────────────────────────────────────┘
    ↓
┌─────────────────────────────────────┐

│ Проверяет ответ на галлюцинации,    │
│ фактические ошибки                  │
└─────────────────────────────────────┘
    ↓
Ответ пользователю
```

## ⚔️ Пост 3: Sentinel — автоматическая защита цен

### Версия для VK (длинная)

**Заголовок:** Sentinel: как работает автоматическая защита цен 24/7

**Текст:**

Представьте: вы спите, а конкурент снизил цену на ваш товар на WB. Маркетплейс автоматически применил скидку, и теперь вы продаёте в минус.

Sentinel решает эту проблему за вас. Автоматически. Каждые 30 минут.

**⚙️ Как работает цикл Sentinel**

```
Каждые 30 минут:
1. Получить список товаров пользователя
2. Запросить текущие цены с WB/Ozon API
3. Для каждого товара:
   ├─ Проверить: цена < стоп-лосс?
   │  └─ ДА → Обнулить остаток ИЛИ Поднять цену
   ├─ Проверить: СПП съедает маржу?
   │  └─ ДА → Пересчитать min_price с буфером
   └─ Проверить: конкурент демпингует?
      └─ ДА → Уведомить (опционально подстроиться)
4. Отправить отчёт пользователю
```

**🛡️ Режимы защиты**

**1. Zero Stock (Обнуление остатка)**

- Самый безопасный
- При цене ниже стоп-лосса → остаток = 0
- Товар исчезает из поиска
- Вы не продаёте в убыток

**2. Price Correction (Коррекция цены)**

- Автоматически поднимает цену до min_price
- Товар остаётся в продаже
- Требует API ключ с правами на изменение цен

**🧮 Умный стоп-лосс с буфером СПП**

Проблема: WB применяет СПП (скидку 10-30%), которую вы не контролируете.

Решение: Вы указываете "минимум для покупателя" = 1000₽, система автоматически рассчитывает стоп-лосс = 1333₽ (с учётом СПП 25%).

Формула:

```
min_price = target_buyer_price / (1 - spp_buffer%)
```

Результат: Покупатель видит 1000₽, ваша маржа защищена.

**📊 Статистика работы**

За последний месяц Sentinel:

- Обработал 15,000+ товаров
- Обнаружил 230 угроз
- Предотвратил убытки на ~450,000₽

**🔔 Уведомления**

Вы получаете отчёт только когда:

- Сработала защита
- Обнаружена критическая угроза
- Есть ошибки API

Никакого спама. Только важное.

**Sentinel работает, пока вы спите. Ваша прибыль под защитой 24/7.**

## 💡 Пост 4: Цифровое зрение — проверка реальных цен

### Версия для VK (длинная)

**Заголовок:** Цифровое зрение: как Виктор видит реальные цены покупателей

**Текст:**

Вы установили цену 1500₽ в кабинете WB. Но покупатель видит 1125₽ (СПП 25%). Вы об этом даже не знаете.

Результат: маржа ниже ожидаемой, возможно — убыток.

**👁️ Инструмент get_real_price**

Виктор теперь умеет проверять, какую цену видит покупатель прямо сейчас.

**Как работает:**

1. **Динамический API** — запрос к `card.wb.ru/cards/v2/detail` (мобильное API WB)
2. **Basket Sharding** — если динамический заблокирован, используем статический `basket-XX.wbbasket.ru`
3. **Fallback на поиск** — если и это не работает, Виктор ищет цену через Google

**Пример использования:**

```
Вы: "Виктор, какая реальная цена на артикул 123456?"

Виктор:
📊 Реальная цена для покупателя: 1125₽
💰 Ваша цена в кабинете: 1500₽
📉 СПП (скидка WB): ~25%
⚠️ Ваша маржа: 18% (ожидали 25%)
```

**Почему это важно:**

- WB может применить СПП без вашего ведома
- Акции маркетплейса снижают вашу прибыль
- Конкуренты видят другую цену, чем вы

**Что делать:**

1. Проверить реальную цену через Виктора
2. Если маржа слишком низкая → поднять базовую цену
3. Использовать "Умный стоп-лосс" с буфером СПП

**Виктор видит то, что видят ваши покупатели. Теперь и вы тоже.**
