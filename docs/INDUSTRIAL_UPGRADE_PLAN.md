# 🏗️ NeuroGUARDIAN Industrial Upgrade Plan

**Цель:** Довести проект до 100% готовности к промышленной эксплуатации, обеспечив масштабируемость, абсолютную безопасность и автономность ("Flash-Drive Mode").

---

## 1. 🚀 Архитектура Масштабирования (Fan-Out)

- [ ] **Переход на Worker-модель**: Расщепление `runCycle` на атомарные задачи через `Inngest`.
- [ ] **Параллельная защита**: Каждый товар проверяется в отдельном потоке (concurrency 50+).
- [ ] **Local-First Worker**: Оптимизация Docker контейнера для запуска BrowserEyes локально (поддержка "флешки").

## 2. 🔐 Сверх-безопасность (Hardened Security)

- [ ] **Encryption Layer (AES-256-GCM)**: Все API-ключи в базе должны храниться только в зашифрованном виде.
- [ ] **Master Key Management**: Подготовка интерфейса для подключения AWS KMS / HashiCorp Vault.
- [ ] **Zero-Knowledge-Lite**: Добавление соли и уникальных IV (Initialization Vector) для каждого зашифрованного ключа.

## 3. 🕸️ Промышленный Парсинг (Digital Vision Ops)

- [ ] **Proxy-Adapter**: Создание слоя абстракции для подключения резидентных прокси (BrightData/SmartProxy).
- [ ] **Anti-Fingerprinting**: Усиление стелс-режима BrowserEyes для имитации различных устройств и браузеров.
- [ ] **Captcha-Bypass Ready**: Создание хуков для подключения сервисов решения капчи.

## 4. 📊 Мониторинг и Observability

- [ ] **Sentinel Health Dashboard**: Монитор качества парсинга и задержек в реальном времени.
- [ ] **Industrial Audit Log**: Неизменяемые логи действий бота (кто, когда и почему изменил цену).
- [ ] **Regression Guard**: Автоматизированная проверка верстки WB/Ozon (если верстка сломалась — система мгновенно сообщает об этом).

## 5. 💾 Автономность (Flash-Drive / Portable Mode)

- [ ] **Self-Contained Docker Suite**: Полный стек (DB + Redis + Inngest + Bot) в едином Docker-образе.
- [ ] **Local SQLite Fallback**: Возможность работы без облачного Postgres для полной изоляции.
- [ ] **USB-Trigger scripts**: Скрипты автозапуска системы при подключении накопителя.

---

**Текущий фокус Antigravity:** Максимальная имплементация прототипов этих модулей прямо сейчас.
