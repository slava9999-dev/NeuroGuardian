## Структура приложения

### Главное меню (нижняя навигация)

| Иконка | Раздел    | Описание                               |
| ------ | --------- | -------------------------------------- |
| 🏠     | Главная   | Дашборд с основной статистикой         |
| 📦     | Товары    | Список товаров, защита цен, стоп-лоссы |
| 💬     | Виктор    | Чат с AI-ассистентом                   |

## Страница "Настройки" (⚙️)

### Раздел "API Ключи маркетплейсов"

**Кнопка "Добавить аккаунт"** — открывает форму подключения маркетплейса.

**Поля для Wildberries:**

- `Название` — ваше название магазина (для себя)
- `API Ключ` — токен из ЛК Wildberries

**Поля для Ozon:**

- `Название` — ваше название магазина
- `Client ID` — ID клиента из ЛК Ozon
- `API Ключ` — секретный ключ API

**Кнопка "Сохранить"** — сохраняет ключи (шифруются!)
**Кнопка "Удалить"** — удаляет подключённый аккаунт

### Раздел "Подписка"

Показывает текущий план:

- `FREE` — бесплатный, ограниченный функционал
- `PRO` — полный доступ ко всем функциям

**Кнопка "Оформить подписку"** — переход к выбору тарифа

### Раздел "Защита цен"

- **Переключатель "Автоматическая защита"** — включает/выключает Sentinel
- **Режим защиты:**
  - `Обнуление остатков` — при атаке обнуляет остатки
  - `Коррекция цены` — автоматически выставляет минимальную цену

## Страница "Товары" (📦)

### Верхняя панель

- **Переключатель "WB / Ozon"** — выбор маркетплейса
- **Кнопка "Синхронизировать"** — загружает товары с маркетплейса
- **Поиск** — фильтр по названию/артикулу

### Карточка товара

Каждый товар показывает:

- 📷 Фото товара
- 📝 Название
- 🔢 Артикул (SKU / nm_id)
- 💰 Текущая цена
- 🛡️ Минимальная цена (стоп-лосс)
- 📊 Остатки

**Кнопки на карточке:**

- **"Установить стоп-лосс"** — задать минимальную цену защиты
- **"Себестоимость"** — указать закупочную цену
- **"Изменить цену"** — изменить цену на маркетплейсе

### Массовые действия

- **Кнопка "Выбрать все"** — выделяет все товары
- **Кнопка "Установить стоп-лосс"** — массовая установка защиты
- **Кнопка "Синхронизировать цены"** — обновить цены

## Страница "Главная" (🏠)

### Обзор

- **Карточка "Товаров под защитой"** — сколько товаров с установленным стоп-лоссом
- **Карточка "Предотвращено атак"** — сколько раз сработала защита
- **Карточка "Экономия за месяц"** — примерная сумма сохранённых денег

### График

- **История изменений цен** — показывает когда срабатывала защита

## Страница "Виктор" (💬)

### Чат

- **Поле ввода** — напишите любой вопрос или команду
- **Кнопка отправки** — отправить сообщение
- **Быстрые действия** — кнопки под ответом агента

### Что может Виктор

1. **Показать товары** — "Покажи мои товары"
2. **Статистика продаж** — "Какие продажи за неделю?"
3. **Установить стоп-лосс** — "Установи минимальную цену 1000₽ на Артикул-123"
4. **Анализ конкурентов** — "Найди конкурентов для [ссылка на товар]"
5. **Юнит-экономика** — "Посчитай unit-economics для товара X"
6. **Изменить цену** — "Измени цену на 2500₽ для товара Y"

## Кнопки быстрых действий в Telegram

После ответа Виктора могут появляться кнопки:

- ✅ **"Применить"** — выполнить предложенное действие
- ❌ **"Отмена"** — отменить
- 🛡️ **"Настроить защиту"** — перейти к настройкам
- 📊 **"Статус"** — показать текущее состояние

| Иконка | Значение                             |

| 🟡     | Предупреждение, требуется внимание   |
| 🔴     | Критическая проблема, нужно действие |

## Onboarding (Первый запуск)

При первом входе рекомендуется:

1. **Открыть Настройки** → Добавить API ключи
2. **Синхронизировать товары** → Страница Товары → Кнопка "Синхронизировать"
3. **Установить стоп-лоссы** → Выбрать товары → "Установить стоп-лосс"
4. **Включить защиту** → Настройки → Переключатель защиты
5. **Готово!** → Виктор начнёт мониторить ваши цены 24/7
