# Безопасность аккаунта селлера

tags: [безопасность, взлом, защита, фишинг, мошенничество]

## Основные угрозы для продавцов

### 1. Фишинг

Мошенники отправляют поддельные письма или SMS от имени WB/Ozon с просьбой перейти по ссылке и ввести данные.

**Как распознать:**

- Домен не seller.wildberries.ru, а что-то похожее (seller-wb.ru)
- Срочность: "Ваш аккаунт будет заблокирован через 24 часа"
- Просьба ввести пароль или код из SMS

**Защита:**

- Никогда не переходить по ссылкам из писем
- Всегда вводить адрес сайта вручную
- Проверять SSL-сертификат (замок в адресной строке)

### 2. Звонки мошенников

Звонят якобы из "поддержки маркетплейса" и просят код из SMS.

**Правило:** Сотрудники маркетплейсов НИКОГДА не звонят и не просят коды. Если звонят — это 100% мошенники.

### 3. Риски с сотрудниками

Если дать полный доступ сотруднику, он может:

- Изменить цены
- Вывести деньги
- Удалить товары

**Защита:**

- Никогда не давать полный доступ
- Использовать роли с ограниченными правами (на Ozon: "Управляющий")
- При увольнении сразу менять API ключи

### 4. Утечка API ключа

Если ключ попал в чужие руки — злоумышленник может:

- Изменить все цены
- Обнулить остатки
- Получить доступ к статистике

**Что делать:**

1. Немедленно отозвать ключ в ЛК маркетплейса
2. Создать новый ключ
3. Обновить ключ в NeuroGUARDIAN

## Чеклист безопасности

- [ ] Регистрирую кабинет только на свой телефон и email
- [ ] Не передаю пароли и коды никому
- [ ] Использую уникальный пароль для маркетплейса
- [ ] Проверяю URL перед входом
- [ ] Меняю API ключи при увольнении сотрудников
- [ ] Не храню ключи в общих чатах
