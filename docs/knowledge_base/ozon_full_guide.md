# Полный гид по работе с Ozon (2025-2026)

tags: [ozon, guide, api, prices, logistics, promotions]

## Основные понятия

### Seller API vs Performance API

- **Seller API** — управление товарами, ценами, остатками
- **Performance API** — реклама и продвижение

### Схемы работы

- **FBO (Fulfillment by Ozon)** — товар на складе Ozon, они отвечают за логистику
- **FBS (Fulfillment by Seller)** — товар у вас, вы отправляете сами
- **realFBS** — экспресс доставка за 2 часа (крупные города)

## Ценообразование

### Структура цены

```
Финальная цена = base_price - discount - ozon_card_discount
```

- `price` — базовая цена продажи
- `old_price` — старая цена (зачёркнутая)
- `premium_price` — цена для Premium подписчиков
- `min_price` — минимальная цена (для защиты от демпинга)

### Ozon Карта (Зелёная цена)

- Скидка покупателю до 30%
- **5% ВСЕГДА за счёт продавца** — это фиксировано!
- Остальное компенсирует Ozon баллами
- Нельзя отключить для конкретных товаров

### Карантин цен

Товар попадает в карантин если:

- Цена резко упала (более чем на 50%)
- Цена значительно ниже рыночной
- Подозрение на ошибку

**Что делать:**

1. Проверить в ЛК раздел "Карантин"
2. Подтвердить цену вручную ИЛИ
3. Установить корректную цену через API

## Комиссии (2025-2026)

### Базовые ставки

| Категория       | Комиссия |
| --------------- | -------- |
| Электроника     | 8-15%    |
| Одежда          | 15-20%   |
| Товары для дома | 15-20%   |
| Автотовары      | 12-18%   |
| Продукты        | 5-12%    |

### Дополнительные сборы

- **Эквайринг**: 1.5% (уже включён в расчёт)
- **Последняя миля**: 5.5% (мин 20₽, макс 500₽)
- **Сборка**: 30-50₽ за заказ
- **Магистраль**: 10-25% от цены

### Тарифы для дешёвых товаров

- До 100₽ — фикс 14%
- 101-300₽ — фикс 20%
- Это МИНИМУМ, независимо от категории

## Логистика FBO

### Стоимость хранения

- Первые 60 дней: бесплатно
- 61-120 дней: 0.5₽/литр/день
- 121+ дней: 1₽/литр/день
- Зимнее хранение сезонки: 0₽ до 31 марта

### Приёмка

- Очереди: 1-3 недели (зависит от склада)
- Штрафы за несоответствие: 50-500₽ за единицу
- Отказ в приёмке: возврат за ваш счёт

## Продвижение

### Типы продвижения

1. **Трафареты** — поисковые продвижение
2. **Продвижение в поиске** — CPM/CPC модель
3. **Брендовая полка** — премиум размещение
4. **Акции Ozon** — участие в распродажах

### Стоимость

- Трафареты: от 2% до 10% от заказа
- Продвижение в поиске: от 50₽ за 1000 показов
- Акции: бесплатно, но скидка за ваш счёт

## API Лимиты

### Rate Limiting

- `POST /v1/product/import/prices`: 100 товаров/запрос
- `POST /v2/product/info`: 1000 товаров/запрос
- Общий лимит: ~10 запросов/секунду

### Ошибки

| Код | Описание          | Решение           |
| --- | ----------------- | ----------------- |
| 400 | Невалидные данные | Проверить payload |
| 401 | Неверный API ключ | Обновить ключ     |
| 403 | Нет доступа       | Проверить права   |
| 429 | Превышен лимит    | Подождать 1 сек   |
| 500 | Ошибка Ozon       | Повторить позже   |

## Частые проблемы и решения

### "Товар в карантине"

**Причина**: Резкое изменение цены
**Решение**: ЛК → Карантин → Подтвердить или исправить цену

### "Нет индекса цен"

**Причина**: Цена выше чем у конкурентов
**Решение**: Проверить цены на WB и Яндекс.Маркет, снизить или улучшить контент

### "Товар не виден в поиске"

**Причина**: Низкий рейтинг, плохой контент, нет отзывов
**Решение**: Улучшить фото, добавить описание, запустить продвижение

### "Заказы идут, но прибыли нет"

**Причина**: Не учтены все комиссии + Ozon Карта
**Решение**: Пересчитать юнит-экономику с учётом 5% Ozon Карты
