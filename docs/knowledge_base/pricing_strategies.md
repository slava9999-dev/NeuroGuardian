# Стратегии ценообразования на маркетплейсах

tags: [ценообразование, цена, маржа, прибыль, стратегия]

## Основные стратегии

### 1. Затратный метод (Cost-Plus)

Цена = Все затраты + Желаемая маржа

**Когда использовать:** Новый товар, неизвестный рынок, нет конкурентов

**Формула:**

```
Цена = (Закупка + Логистика) / (1 - Комиссия%) / (1 - Маржа%) / (1 - СПП%)
```

**Пример:**

- Закупка: 500₽
- Логистика: 100₽
- Комиссия WB: 15%
- Желаемая маржа: 20%
- СПП буфер: 25%
- Итоговая цена: ~1100₽

### 2. Конкурентное ценообразование

Ориентируемся на цены конкурентов.

**Правило:** Смотрите на МЕДИАННУЮ цену, не на минимальную! Минимум часто — это демпинг или ошибка.

**Варианты:**

- Цена = Медиана конкурентов (нейтральная позиция)
- Цена = Медиана - 5% (агрессивная)
- Цена = Медиана + 10% (премиум, если есть выделение)

### 3. Стратегия проникновения

Временно работаем с минимальной маржой или в минус для захвата ниши.

**Когда использовать:**

- Есть ресурсы на 2-3 месяца работы в минус
- Ниша с высоким потенциалом
- Нужно быстро набрать отзывы и позиции

**Риски:**

- Конкуренты могут ответить демпингом
- Можно "застрять" на низкой цене

**Правило:** Заранее определите срок и критерии выхода из стратегии!

### 4. Премиум-ценообразование

Цена выше конкурентов на 15-30%.

**Когда работает:**

- Уникальный товар или бренд
- Качественный контент (фото, видео, rich-контент)
- Много положительных отзывов
- Быстрая доставка (свои склады во всех регионах)

## Ошибки ценообразования

### Ошибка 1: Не учтён СПП

WB может снизить вашу цену на 10-30% через СПП (скидку постоянного покупателя). Если вы не заложили это в цену — маржа уйдёт в минус.

**Решение:** Используйте буфер СПП 20-30%

### Ошибка 2: Забыты возвраты

Каждый возврат — это:

- Логистика туда-обратно (×2)
- Возможная порча товара
- Хранение на складе до повторной продажи

**Решение:** Закладывайте в цену return_rate × стоимость возврата

### Ошибка 3: Демпинг без плана

Снизили цену, чтобы "обогнать конкурента". Он тоже снизил. Вы снова. Итог: все в минусе.

**Решение:** Никогда не демпингуйте реактивно. Если снижаете — только с чётким планом и сроками.

## Формула расчёта минимальной цены

```
min_price = target_buyer_price / (1 - spp_buffer% / 100)
```

**Пример:**

- Хочу, чтобы покупатель платил минимум 1000₽
- СПП обычно 25%
- min_price = 1000 / 0.75 = 1333₽

Это цена, которую нужно установить в кабинете.
