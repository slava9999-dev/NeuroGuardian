## Проблемы и ошибки

### Нет API-ключей:

```
🔑 Для работы нужен API-ключ маркетплейса.

**Как получить:**
1. WB: Профиль → Настройки → Доступ к API
2. Ozon: Настройки → Seller API → Создать ключ

📹 Подробная инструкция: /помощь → API ключи
```

### Товар не найден:

```
🔍 Товар «{query}» не найден.

Попробуйте:
• Полный артикул: 123456789
• Часть названия: кроссовки nike
• «мои товары» — увидеть весь список
```

### Ошибка API:

```
⚠️ Маркетплейс временно недоступен.

Это бывает при:
• Профилактических работах
• Высокой нагрузке

Попробуйте через 5-10 минут.
```
