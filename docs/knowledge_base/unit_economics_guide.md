# Юнит-экономика для маркетплейсов

tags: [unit_economics, margins, profitability, calculation]

## Что такое юнит-экономика?

Юнит-экономика — расчёт прибыли/убытка с ОДНОЙ единицы товара. Если юнит-экономика отрицательная — каждая продажа приносит убыток.

## Формула расчёта

```
Прибыль = Выручка - Себестоимость - Комиссии - Логистика - Скрытые расходы
```

## Компоненты для Ozon

| Статья расходов   | % от цены | Пример (1000₽) |
| ----------------- | --------- | -------------- |
| Себестоимость     | ~40%      | 400₽           |
| Комиссия Ozon     | 15-25%    | 200₽           |
| Логистика ПВЗ     | 5.5%      | 55₽            |
| Сборка            | фикс      | 35₽            |
| Ozon Карта        | 5%        | 50₽            |
| Эквайринг         | 1.5%      | 15₽            |
| **ИТОГО расходы** | **~68%**  | **755₽**       |
| **Прибыль**       | **~32%**  | **245₽**       |

### Важно: Учтите возвраты!

Средний процент возвратов: 5-15%
Стоимость возврата: обратная логистика + потеря товара

## Компоненты для WB

| Статья расходов   | % от цены | Пример (1000₽) |
| ----------------- | --------- | -------------- |
| Себестоимость     | ~40%      | 400₽           |
| Комиссия WB       | 25-35%    | 300₽           |
| Логистика         | формула   | 80₽            |
| СПП (частично)    | 5-10%     | 75₽            |
| **ИТОГО расходы** | **~75%**  | **855₽**       |
| **Прибыль**       | **~25%**  | **145₽**       |

### Важно: СПП непредсказуемый!

СПП зависит от покупателя, не от вас. Закладывайте 10% на СПП.

## Расчёт min_price

```
min_price = Себестоимость / (1 - Total_Commission%)
```

Пример:

- Себестоимость: 400₽
- Все комиссии: 40%
- min_price = 400 / 0.6 = 667₽

**С запасом (рекомендуется):**
min_price = 667 × 1.15 = **767₽**

## Красные флаги

🚩 **Маржа < 20%** — высокий риск убытков
🚩 **Маржа < 10%** — скорее всего уже в минусе
🚩 **Не учтены возвраты** — реальная маржа ниже
🚩 **Не учтена Ozon Карта** — минус 5% сразу

## Рекомендации

1. **Целевая маржа**: 25-35%
2. **Минимальная маржа**: 15%
3. **Буфер безопасности**: +10-15% к min_price
4. **Пересчитывайте** при изменении тарифов (каждые 3 месяца)
