# Правила работы с ценами Wildberries (2026)

tags: [wb, prices, quarantine, api_limits]

## Карантин цен

Wildberries защищает продавцов от случайного демпинга через механизм **Карантина цен**.

- **Условие**: Если цена снижается в 3 раза или более относительно предыдущей.
- **Эффект**: Новая цена не отображается на сайте. Товар продолжает продаваться по старой цене.
- **Действие**: Продавец должен подтвердить изменение в Личном кабинете или через API метод `GET /api/v2/quarantine/goods`.

## Лимиты API

- Используется алгоритм **Token Bucket**.
- Превышение лимита возвращает ошибку **429 Too Many Requests**.
- Заголовок `X-Ratelimit-Retry` указывает время ожидания перед повторным запросом.
- Важно группировать запросы на обновление цен для экономии лимитов.

## Управление ценами

- `price`: Основная цена до скидок.
- `discount`: Процент скидки (целое число).
- Результирующая цена = `price` \* (1 - `discount`/100).
- При работе через API ключи для продавцов бесплатны (по состоянию на 2026).
