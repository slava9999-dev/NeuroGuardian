# Правила работы с ценами Ozon (2026)

tags: [ozon, prices, quarantine, premium_price]

## Типы цен

Ozon поддерживает несколько уровней цен через API:

1. **price**: Текущая цена продажи.
2. **old_price**: Зачеркнутая цена (для отображения скидки). Должна быть выше текущей цены.
3. **premium_price**: Специальная цена для подписчиков Ozon Premium.

## Карантин цен

- Если цена товара значительно отклоняется от рыночной или предыдущей, товар попадает в **Карантин**.
- В карантине товар скрыт с витрины и недоступен для покупки.
- Для выхода из карантина нужно либо подтвердить цену в ЛК, либо установить корректную цену через API.

## Лимиты и Обновления

- За один запрос можно обновить цены до **1000 товаров**.
- Параметр `marketing_price` устарел. Для анализа финальной цены покупателя следует использовать данные о ценовом индексе.
- Изменения тарифов и правил API актуальны с января 2026 года.

## Особенности

- Цену по карте Ozon напрямую через API получить нельзя, она рассчитывается маркетплейсом динамически.

## Индекс ошибок (2025)

- Ozon ввел штрафы за отмены заказов (FBS), зависящие от процента ошибок за 14 дней.
- Если процент отмен > 10%, штраф за каждую отмену вырастает до **13% от цены**.
- API позволяет отслеживать текущие показатели склада для превентивного реагирования.
