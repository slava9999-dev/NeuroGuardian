# Полный гид по работе с Wildberries (2025-2026)

tags: [wb, wildberries, guide, api, prices, logistics, spp]

## Основные понятия

### FBW (Fulfillment by Wildberries)

Единственная схема на WB — товар ТОЛЬКО на складах Wildberries. Нет FBS.

### СПП (Скидка постоянного покупателя)

- Персональная скидка для покупателя: 5-30%
- Зависит от истории покупок клиента
- **Частично** компенсируется WB (снижается комиссия)

## Ценообразование

### Структура цены

```
Финальная цена = price × (1 - discount/100) - СПП
```

- `price` — базовая цена до скидок
- `discount` — ваша скидка в процентах
- СПП — скидка WB для покупателя (частично компенсируется)

### Карантин цен

Срабатывает если:

- Цена снижается в 3+ раза
- Резкое изменение без подтверждения

**Что делать:**

1. API: `GET /api/v2/quarantine/goods`
2. ЛК: Раздел "Карантин цен"
3. Подтвердить или откатить изменение

### Принудительные акции

WB может автоматически включить товар в акцию. Если min_price не установлена — цена упадёт!

**Защита**: Установить min_price через NeuroGUARDIAN Sentinel

## Логистика

### Формула

```
Стоимость = (38₽ + 9.5₽ × (литры - 1)) × КТР
```

- **38₽** — база за первый литр
- **9.5₽** — каждый дополнительный литр
- **КТР** — коэффициент склада (50% - 300%)

### Индекс Локализации

Если ИЛ < 35%, логистика дорожает на 20%

### Обратная логистика

- 50₽ за возврат от покупателя
- НЕВОЗВРАТНАЯ плата

## API Лимиты

### Token Bucket

- При превышении: ошибка 429
- Заголовок `X-Ratelimit-Retry` указывает время ожидания
- Рекомендация: группировать запросы

### Основные endpoints

| Метод                      | Лимит       |
| -------------------------- | ----------- |
| GET /api/v2/prices         | 100 req/min |
| POST /api/v2/prices/update | 50 req/min  |
| GET /api/v2/stocks         | 100 req/min |

### Коды ошибок

| Код | Описание         | Решение                     |
| --- | ---------------- | --------------------------- |
| 400 | Неверный запрос  | Проверить payload           |
| 401 | Невалидный токен | Перегенерировать            |
| 403 | Нет прав         | Проверить тип токена        |
| 429 | Rate limit       | Подождать X-Ratelimit-Retry |
| 500 | Сервер WB        | Повторить через 5 мин       |

## Частые проблемы и решения

### "Цена не меняется на сайте"

**Причина**: Карантин цен (снижение >3x)
**Решение**: Подтвердить в ЛК или API

### "Товар ушёл в минус из-за акции"

**Причина**: WB включил в принудительную акцию
**Решение**: Установить min_price, включить Sentinel защиту

### "Высокие возвраты"

**Причина**: Несоответствие фото/описания или размерная сетка
**Решение**: Обновить контент, добавить таблицу размеров

### "Штраф за габариты"

**Причина**: Упаковка больше заявленных размеров
**Решение**: Перемерить и обновить спецификацию

### "Потери на складе"

**Причина**: Товар потерялся/сломался на складе WB
**Решение**: Подать заявку на компенсацию в течение 30 дней

### "СПП съедает всю маржу"

**Причина**: Высокая персональная скидка у покупателей
**Решение**: Заложить +10-15% в базовую цену
