tags: [faq, questions, help, common]

## 🛡️ Защита цен

### Что такое min_price?

Минимальная цена, ниже которой товар не должен продаваться. Если маркетплейс попытается снизить цену ниже — NeuroGUARDIAN автоматически защитит товар.

### Как работает защита?

1. Sentinel проверяет цены каждые 30 минут
2. Если цена ниже min_price — срабатывает защита
3. Два режима: обнуление стока или коррекция цены
4. Вы получаете уведомление в Telegram

### Что лучше: обнуление стока или коррекция цены?

- **Обнуление стока** — товар временно не продаётся. Безопаснее, но теряете продажи.
- **Коррекция цены** — цена возвращается к min_price. Агрессивнее, может вызвать карантин.

**Рекомендация**: Начните с обнуления стока, переключитесь на коррекцию когда разберётесь.

## 💰 Комиссии и расходы

### Какие скрытые комиссии я могу упустить?

**Ozon:**

- Ozon Карта: 5% (ВСЕГДА за ваш счёт)
- Эквайринг: 1.5%
- Последняя миля: до 5.5%
- Сборка: 30-50₽

**WB:**

- СПП: частично компенсируется, но не полностью
- Обратная логистика: 50₽/возврат
- Хранение: после 15 дней

### Как правильно считать маржу?

```
Маржа = (Цена продажи - Себестоимость - Все комиссии) / Цена продажи × 100%
```

Не забудьте:

- Комиссия маркетплейса
- Логистика (туда + обратно)
- Эквайринг
- Скидки карт (Ozon Card, WB Pay)
- Хранение

## 🔄 API и интеграция

### Какие права нужны для API ключа?

**WB**: Контент → полный доступ, Цены → полный доступ, Статистика → чтение
**Ozon**: Seller API → полный доступ

### Безопасно ли давать вам API ключи?

Да. Ключи:

- Хранятся в зашифрованном виде
- Передаются по HTTPS
- Никогда не отображаются в интерфейсе
- Не продаются третьим лицам

Вы можете отозвать ключ в любой момент в ЛК маркетплейса.

### Можно ли подключить несколько магазинов?

Да! На тарифах Pro и Business можно подключить несколько магазинов на обоих маркетплейсах.

## 🛠️ Проблемы и решения

### Товар попал в карантин после защиты

Это нормально если использовался режим "коррекция цены".
**Решение**: Подтвердите цену в ЛК маркетплейса или переключитесь на "обнуление стока".

### Защита не сработала вовремя

Возможные причины:

1. Проверка идёт каждые 30 минут — могла попасть между проверками
2. Нестабильный интернет у нас (редко)
3. API маркетплейса не отвечает

### Бот не отвечает

1. Проверьте что бот не заблокирован
2. Попробуйте /start
3. Подождите 1-2 минуты (высокая нагрузка)
4. Напишите в поддержку

### Не приходят уведомления

1. Проверьте что Telegram уведомления включены в телефоне
2. Проверьте что чат с ботом не замьючен
3. Попробуйте /start

## 🔒 Безопасность

### Вы можете менять мои цены без разрешения?

Нет! Каждое критическое действие требует подтверждения. Автоматические действия (защита) настраиваются вами заранее и могут быть отключены.

### Что если ваш сервис взломают?

API ключи хранятся зашифрованными. Даже при утечке — расшифровать их крайне сложно. Дополнительно — логируем все действия для аудита.

### Соответствуете ли вы 152-ФЗ?

Да. Персональные данные обрабатываются в соответствии с законодательством РФ.
