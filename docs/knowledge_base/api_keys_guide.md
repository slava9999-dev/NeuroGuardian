# Как получить API ключи для Wildberries и Ozon

tags: [api, keys, wildberries, ozon, setup, onboarding, instructions]

## Wildberries

### Пошаговая инструкция

#### Шаг 1: Войдите в личный кабинет

1. Откройте [seller.wildberries.ru](https://seller.wildberries.ru)
2. Войдите под своим аккаунтом продавца

#### Шаг 2: Перейдите в настройки API

1. Нажмите на свой профиль (иконка в правом верхнем углу)
2. Выберите **"Настройки"**
3. В левом меню выберите **"Доступ к API"**

Или перейдите напрямую: [seller.wildberries.ru/supplier-settings/access-to-api](https://seller.wildberries.ru/supplier-settings/access-to-api)

#### Шаг 3: Создайте новый токен

1. Нажмите кнопку **"Создать новый токен"**
2. Введите название (например: "NeuroGUARDIAN")
3. **ВАЖНО:** Выберите следующие права:
   - ✅ **Контент** — чтение карточек товаров
   - ✅ **Цены и скидки** — управление ценами
   - ✅ **Маркетплейс** — информация о продажах
   - ✅ **Статистика** — аналитика
   - ✅ **Продвижение** — для рекламных функций (опционально)

4. Нажмите **"Создать токен"**

#### Шаг 4: Скопируйте токен

1. **ВАЖНО:** Токен показывается ТОЛЬКО ОДИН РАЗ!
2. Нажмите иконку копирования 📋
3. Сохраните токен в надёжном месте
4. Вставьте токен в приложение NeuroGUARDIAN

### Формат токена Wildberries

Токен WB выглядит примерно так:

```
eyJhbGciOiJFUzI1NiIsInR5cCI6IkpXVCJ9.eyJhY2Nlc3NJRC...
```

(Длинная строка, начинается с "eyJ...")

### Частые ошибки

❌ **"Неверный токен"**

- Убедитесь, что скопировали токен полностью
- Проверьте, нет ли пробелов в начале/конце

❌ **"Нет доступа"**

- Проверьте права токена (нужны Цены и скидки)
- Возможно, токен деактивирован в ЛК

❌ **"Токен истёк"**

- Создайте новый токен в ЛК Wildberries
- Старые токены действуют ограниченное время

## Ozon

### Пошаговая инструкция

#### Шаг 1: Войдите в личный кабинет

1. Откройте [seller.ozon.ru](https://seller.ozon.ru)
2. Войдите под своим аккаунтом продавца

#### Шаг 2: Перейдите к API ключам

1. В левом меню нажмите **⚙️ Настройки**
2. Выберите **"Seller API"**

Или перейдите напрямую: [seller.ozon.ru/app/settings/api-keys](https://seller.ozon.ru/app/settings/api-keys)

#### Шаг 3: Получите Client ID

1. На странице API вверху указан ваш **Client ID**
2. Это числовой идентификатор (например: `123456`)
3. Скопируйте его

#### Шаг 4: Создайте API ключ

1. Нажмите кнопку **"Сгенерировать ключ"**
2. При создании выберите тип токена: **Admin** (полный доступ)
3. Введите название: "NeuroGUARDIAN"
4. Нажмите **"Сгенерировать"**

#### Шаг 5: Скопируйте API ключ

1. **ВАЖНО:** Ключ показывается ТОЛЬКО ОДИН РАЗ!
2. Скопируйте ключ в буфер обмена
3. Сохраните в надёжном месте
4. Вставьте в приложение NeuroGUARDIAN

### Формат ключей Ozon

**Client ID** (числовой):

```
123456
```

**API Key** (строка с дефисами):

```
0a1b2c3d-4e5f-6g7h-8i9j-0k1l2m3n4o5p
```

### Права API ключа Ozon

Для полной работы Viktor AI нужен ключ с правами:

- ✅ Управление товарами и ценами
- ✅ Чтение заказов
- ✅ Управление остатками
- ✅ Чтение статистики

**Рекомендация:** Создайте ключ с типом **Admin** — он имеет все необходимые права.

### Частые ошибки

❌ **"Invalid credentials"**

- Проверьте Client ID (должен быть числом)
- Проверьте API Key (длинная строка с дефисами)

❌ **"Forbidden"**

- API ключ не имеет нужных прав
- Создайте новый ключ типа Admin

❌ **"Key not found"**

- Ключ был удалён в ЛК Ozon
- Создайте новый ключ

## Безопасность

### Как мы храним ваши ключи

1. ✅ **Шифрование AES-256** — ключи шифруются перед сохранением
2. ✅ **Раздельное хранение** — ключ шифрования отделён от данных
3. ✅ **Нет логирования** — ключи никогда не пишутся в логи
4. ✅ **HTTPS only** — все запросы через защищённый канал

### Рекомендации

1. **Создавайте отдельный токен** для NeuroGUARDIAN
2. **Не используйте главный токен** с полными правами
3. **Периодически обновляйте** токены (раз в 3-6 месяцев)
4. **При утере доступа** — сразу деактивируйте токен в ЛК маркетплейса
