# Комиссии Wildberries 2026 (Базовые)

tags: [wb, commission, fees, wildberries]

## Основные тарифы (FBO/FBS)

| Категория       | Комиссия FBO | Комиссия FBS |
| --------------- | ------------ | ------------ |
| Одежда          | 25%          | 25%          |
| Обувь           | 25%          | 25%          |
| Аксессуары      | 23%          | 23%          |
| Электроника     | 15%          | 15%          |
| Бытовая техника | 15%          | 15%          |
| Товары для дома | 19%          | 19%          |
| Красота         | 17%          | 17%          |

_Примечание: Комиссия может меняться в зависимости от СПП (Скидки Постоянного Покупателя), которую WB компенсирует частично._

## Логистика

- **Базовая стоимость:** от 50₽ за 1 литр + 15₽ за каждый дополнительный литр.
- **Минимальная логистика:** 60₽ (для мелких товаров FBO).

## Хранение

- **Короб:** ~0.25₽ в день за литр.
- **Монопаллета:** ~50₽ в день.

## Эквайринг

Включен в комиссию WB.
