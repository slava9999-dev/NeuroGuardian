# 💰 Сводка Штрафов и Санкций Маркетплейсов (Quick Reference)

Этот файл предназначен для быстрого доступа агентов к цифрам и "Blast Radius" (растущему ущербу) при нарушениях.

## 🟢 Wildberries (WB)

| Нарушение                 | Штраф / Санкция                   | Примечание                         |
| :------------------------ | :-------------------------------- | :--------------------------------- |
| **Отмена заказа (FBS)**   | 35-50% цены (мин. 100₽)           | Крайне опасно для дешевых товаров  |
| **Подмена товара**        | до 100% цены (мин. 100₽)          | + Логистика возврата               |
| **Неверные габариты**     | Коэф. логистики x25 + 1000-10000₽ | Действует на всю партию 7 дней     |
| **Вредители (грызуны)**   | 10к -> 50к -> 100к                | Прогрессивная шкала за каждый факт |
| **Накрутка отзывов**      | 50 000₽ + блокировка              | При рейтинге < 4.0 — бан           |
| **Контакты в упаковке**   | 25 000₽                           | За каждую обнаруженную визитку/QR  |
| **Нет маркировки ТН ВЭД** | 1 500₽ за единицу                 | Critical для одежды/обуви          |

## 🔵 Ozon

| Нарушение               | Штраф / Санкция           | Примечание                           |
| :---------------------- | :------------------------ | :----------------------------------- |
| **Индекс ошибок > 10%** | до 13% от цены за отмену  | Считается за 14 дней                 |
| **Нарушение контента**  | 1 000₽ за карточку        | Если не исправить за 24 часа         |
| **Критический бан**     | 1200 баллов               | Удаление кабинета без права возврата |
| **Дубли карточек**      | 200 баллов                | Сгорают через 2 месяца               |
| **Высокий Индекс Цен**  | Shadow ban (пессимизация) | Сравнение с WB в реальном времени    |
| **Самовыкупы**          | 350 баллов                | Резкая потеря позиций в поиске       |

## 🛡️ Стратегии защиты NeuroGuardian

1.  **Safety Buffer:** Всегда держать 5-10% маржи на "скрытые комиссии" и рост логистики.
2.  **Sentinel Monitoring:** При обнаружении роста "Индекса ошибок" на Ozon — автоматически переводить заказы на realFBS (если возможно) или временно обнулять остатки до исправления ситуации.
3.  **Content QA:** Vision-агент должен проверять карточки на наличие запрещенных элементов (контактов, QR) перед апрувом.
