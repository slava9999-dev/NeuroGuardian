# Буфер СПП — как защитить маржу

tags: [спп, буфер, стоп-лосс, защита, маржа, цена покупателя]

## Что такое СПП

**СПП** (Скидка Постоянного Покупателя) — это скидка, которую WB применяет к вашему товару для покупателей. Вы её не контролируете.

**Размер СПП:** от 5% до 35%, зависит от:

- Категории товара
- Истории покупок клиента
- Акций WB
- Региона

## Проблема

Вы установили цену **1000₽** в кабинете WB.
WB применил СПП **25%**.
Покупатель видит **750₽**.
Ваша маржа меньше на 250₽!

Если вы рассчитывали маржу исходя из 1000₽ — можете уйти в минус.

## Решение: Буфер СПП

Вместо того чтобы устанавливать стоп-лосс (минимальную цену) напрямую, задайте:

1. **Минимальная цена ДЛЯ ПОКУПАТЕЛЯ** (target_buyer_price) — сколько покупатель должен заплатить минимум
2. **Буфер СПП** (spp_buffer_percent) — ожидаемый размер скидки WB (обычно 25%)

Система автоматически рассчитает стоп-лосс:

```
min_price = target_buyer_price / (1 - spp_buffer / 100)
```

## Пример

**Ваши настройки:**

- Минимум для покупателя: 1000₽
- Буфер СПП: 25%

**Расчёт системы:**

- Стоп-лосс = 1000 / 0.75 = **1333₽**

**Результат:**

- Вы ставите 1333₽ в кабинете WB
- WB применяет СПП 25%
- Покупатель видит ~1000₽ ✅
- Ваша маржа защищена!

## Рекомендуемые значения буфера

| Маркетплейс | Категория       | Буфер |
| ----------- | --------------- | ----- |
| WB          | Одежда, обувь   | 30%   |
| WB          | Электроника     | 20%   |
| WB          | Косметика       | 25%   |
| WB          | Товары для дома | 25%   |
| Ozon        | Все категории   | 15%   |

**Важно:** Это средние значения. Отслеживайте реальный СПП на ваших товарах и корректируйте!

## Как включить в NeuroGUARDIAN

1. Откройте настройки товара
2. Укажите "Минимальная цена для покупателя"
3. Укажите "Буфер на скидки" (по умолчанию 25%)
4. Включите "Автоматически корректировать"

Sentinel будет автоматически пересчитывать стоп-лосс каждые 30 минут.
