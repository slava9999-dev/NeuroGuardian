## 📊 Что такое Unit Economics?

**Unit Economics** — это расчёт прибыли с ОДНОГО заказа с учётом ВСЕХ затрат.

**Формула:**

```
Чистая прибыль = Цена продажи
                 - Себестоимость
                 - Комиссия маркетплейса
                 - Логистика
                 - Ozon Card (если Ozon)
                 - Хранение
                 - Возвраты
                 - Эквайринг
                 - СПП
                 - Упаковка
```

**Почему это важно:**

- ❌ Многие селлеры считают только комиссию МП
- ❌ Забывают про Ozon Card (5% за ваш счёт!)
- ❌ Не учитывают рост тарифов хранения
- ❌ Игнорируют возвраты

**Результат:** Товар кажется прибыльным, но на деле убыточный.

## 🔍 Детальный breakdown

### 1. Выручка (Revenue)

```typescript
revenue = sellingPrice;
```

**Пример:** Товар продаётся за 2000₽ → revenue = 2000₽

---

### 2. Себестоимость (Cost Price)

```typescript
costPrice = yourPurchasePrice;
```

**Важно:**

- Цена закупки товара
- НЕ включает доставку до вас
- НЕ включает упаковку

**Пример:** Купили товар за 800₽ → costPrice = 800₽

---

### 3. Комиссия маркетплейса (Commission)

```typescript
commission = sellingPrice * commissionRate;
```

**Тарифы 2025 (актуальные):**

| Одежда          | 25%      |

| Бытовая техника | 15%      |

```
2000₽ * 12% = 240₽
```

---

### 4. Логистика (Logistics)

```typescript
logistics = firstMile + lastMile;
```

#### First Mile (до склада МП):

- **WB:** ~30-50₽ (зависит от региона)
- **Ozon:** ~25-40₽

#### Last Mile (от склада до покупателя):

- **WB:** Рассчитывается по тарифам (вес + объём)
- **Ozon:** Аналогично

**Формула WB:**

```typescript
lastMile = Math.max(
  volumeLiters * 4, // 4₽ за литр
  50 // Минимум 50₽
);
```

**Пример (1 литр):**

```
firstMile = 40₽
lastMile = max(1 * 4, 50) = 50₽
total = 90₽
```

---

### 5. Ozon Card (КРИТИЧНО!)

```typescript
ozonCardCosts = sellingPrice * 0.05 * 0.4;
```

**Что это:**

- Скидка 5% по карте Ozon
- Оплачивается ПРОДАВЦОМ, не Ozon!
- ~40% покупок на Ozon с картой

**Пример:**

```
2000₽ * 5% * 40% = 40₽ средний убыток
```

**Годовой impact:**

```
40₽ * 1000 заказов = 40,000₽ в год!
```

**⚠️ ВАЖНО:**
Многие селлеры не знают об этом и теряют деньги!

---

### 6. Хранение (Storage)

```typescript
storage = baseCost * multiplier;
```

**Wildberries тарифы:**

- **0-60 дней:** Базовый тариф (например, 10₽/день)
- **61-90 дней:** Тариф x2 (20₽/день)
- **90+ дней:** Тариф x4 (40₽/день) + риск утилизации

**Пример (товар 70 дней на складе):**

```
60 дней * 10₽ = 600₽
10 дней * 20₽ = 200₽
total = 800₽
```

**⚠️ ПРЕДУПРЕЖДЕНИЕ:**
Viktor Margin предупреждает на 45-м дне!

---

### 7. Возвраты (Returns)

```typescript
returnCosts = sellingPrice * returnRate * returnLogisticsCost;
```

**Средние показатели:**

- **Одежда/Обувь:** 20-30% возвратов
- **Электроника:** 5-10%
- **Товары для дома:** 10-15%

**Логистика возврата:**

- ~80₽ за возврат (за ваш счёт!)

**Пример (одежда, 25% возвратов):**

```
returnCosts = 2000₽ * 0.25 * 80₽ = 40₽ на заказ
```

---

### 8. Эквайринг (Acquiring)

```typescript
acquiring = sellingPrice * acquiringRate;
```

**Тарифы:**

- **WB:** 2.0%
- **Ozon:** 1.5%

**Пример (Ozon):**

```
2000₽ * 1.5% = 30₽
```

---

### 9. СПП (Self-Purchase Protection)

```typescript
spp = sellingPrice * sppRate;
```

**Что это:**

- Скидка за участие в акциях МП
- Обычно 5-15%

**Пример (10% СПП):**

```
2000₽ * 10% = 200₽
```

---

### 10. Упаковка (Packaging)

```typescript
packagingCost = customPackaging || defaultPackaging;
```

**Средние затраты:**

- Пакет: 5-10₽
- Коробка: 15-30₽
- Пузырчатая плёнка: 5-15₽

**Default:** 15₽

## 📊 ПОЛНЫЙ ПРИМЕР РАСЧЁТА

### Товар: Кроссовки спортивные (Ozon)

**Входные данные:**

```
Цена продажи: 2000₽
Себестоимость: 800₽
Категория: Обувь
Объём: 5 литров
Хранение: 45 дней
Возвраты: 25%
```

**Расчёт:**

1. **Выручка:** 2000₽

2. **Себестоимость:** 800₽

3. **Комиссия Ozon (20%):** 2000₽ \* 20% = **400₽**

4. **Логистика:**
   - First mile: 35₽
   - Last mile: max(5 \* 4, 50) = 50₽
   - **Total: 85₽**

5. **Ozon Card:** 2000₽ _ 5% _ 40% = **40₽**

6. **Хранение (45 дней):** 45 \* 10₽ = **450₽**

7. **Возвраты:** 2000₽ _ 0.25 _ 80₽ = **400₽**

8. **Эквайринг (1.5%):** 2000₽ \* 1.5% = **30₽**

9. **СПП (10%):** 2000₽ \* 10% = **200₽**

10. **Упаковка:** **20₽**

**Итого затраты:**

```
800₽ (себестоимость)
+ 400₽ (комиссия)
+ 85₽ (логистика)
+ 40₽ (Ozon Card)
+ 450₽ (хранение)
+ 400₽ (возвраты)
+ 30₽ (эквайринг)
+ 200₽ (СПП)
+ 20₽ (упаковка)
= 2425₽
```

**Чистая прибыль:**

```
2000₽ - 2425₽ = -425₽ (УБЫТОК!)
```

**Маржа:**

```
-425₽ / 2000₽ * 100% = -21.25%
```

**⚠️ ВЫВОД:**
Товар кажется прибыльным (цена 2000₽, себестоимость 800₽), но на деле убыточный из-за скрытых затрат!

## 🚨 Критические warnings

### 1. NEGATIVE_PROFIT

**Когда:** profit < 0

**Пример:**

```
🚨 Товар продается в убыток!
Чистая прибыль: -425₽
```

**Действие:** Срочно пересмотреть цену или себестоимость!

---

### 2. OZON_CARD_IMPACT

**Когда:** ozonCardCosts > price \* 0.015 (>1.5%)

**Пример:**

```
⚠️ Скидка Ozon Card съедает 40₽ (2.0%) с каждого заказа!
При 1000 заказов в год вы теряете 40,000₽ маржи.
Учтите это при ценообразовании!
```

**Действие:** Заложить в цену или учесть в прогнозах.

---

### 3. HIGH_STORAGE_DAYS

**Когда:** avgStorageDays > 45 (WB)

**Пример (50 дней):**

```
⚠️ Товар на складе 50 дней!
Через 10 дней тариф удвоится!
Планируйте распродажу ДО 60-го дня.
```

**Пример (70 дней):**

```
🚨 Товар на складе 70 дней!
Тариф хранения уже x2.
Через 20 дней будет x4!
Планируйте распродажу.
```

**Пример (100 дней):**

```
🚨 Товар на складе 100 дней!
Тариф хранения уже x4 (400₽).
Срочно распродавайте или вывозите!
```

**Действие:** Распродажа, акции, или вывоз со склада.

---

### 4. HIGH_RETURN_RATE

**Когда:** returnRate > 0.15 (>15%)

**Пример (20%):**

```
⚠️ Высокий процент возвратов (20%)!
Это съедает 320₽ с каждого заказа.
Улучшите описание товара, размерную сетку и фото.
```

**Пример (30%):**

```
🚨 Критический процент возвратов (30%)!
Это съедает 480₽ с каждого заказа.
Срочно улучшите описание товара, размерную сетку и фото.
```

**Действие:** Улучшить карточку товара, размерную сетку, фото.
